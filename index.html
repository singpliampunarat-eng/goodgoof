How to Get Your Keys

01 Supabase URL & Anon Key
1. Go to supabase.com → sign up or log in
2. Click "New Project" → name it anything
3. Once created, go to Settings → API (or click Connect)
4. Copy "Project URL" → paste as SUPABASE_URL in secrets.js
5. Copy "anon / publishable" key → paste as SUPABASE_KEY
6. Run this SQL in Supabase SQL Editor:
create table messages (
  id bigint generated always as identity primary key,
  text text not null,
  sender text default 'anonymous',
  category text,
  status text default 'pending',
  screenshot_url text,
  created_at timestamptz default now()
);

alter table messages enable row level security;
create policy "public_access" on messages for all using (true);

-- Storage bucket for screenshots
insert into storage.buckets (id, name, public)
values ('screenshots', 'screenshots', true);

-- Allow public uploads to screenshots bucket
create policy "public_upload" on storage.objects
  for all using (bucket_id = 'screenshots');
02 Gemini API Key (free)
1. Go to aistudio.google.com
2. Sign in with any Google account
3. Click "Get API key" in the left sidebar
4. Click "Create API key" → pick new project
5. Copy the key → paste as GEMINI_API_KEY in secrets.js
Free tier: 60 req/min — more than enough
03 Instagram Access Token & User ID
1. Switch your IG account to Business or Creator
2. Go to developers.facebook.com → Create App
3. Choose "Other" → "Business" type → create
4. Add the "Instagram Graph API" product
5. Open Tools → Graph API Explorer
6. Select your app and add these permissions:
instagram_basic
instagram_content_publish
pages_show_list
7. Click "Generate Access Token" → authorize
8. Copy token → paste as IG_ACCESS_TOKEN in secrets.js
9. Run GET /me?fields=id → copy the ID → paste as IG_USER_ID
10. Extend token: Access Token Debugger → "Extend Access Token"
Token lasts 60 days — refresh before it expires
04 Tellonym Inbox Feed
1. Tellonym has no public API
2. Option A: Build a Node.js scraper on Replit
3. Option B: Manually paste messages into Supabase
4. Scraper should INSERT rows into 'messages' table
5. Set on a cron interval (every 5 min)
05 Deploy
1. Upload this entire folder to Replit (or Vercel/Netlify)
2. Edit secrets.js with your real keys
3. That's it — open index.html and you're live
For Replit: just drag & drop the folder
